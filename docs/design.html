MacroPad Mixer

A volume mixer you can put your hand on. Every key becomes an app that is playing sound, shown with its logo and brand colour, and the knob turns that app up or down without touching the rest of your audio. Key 12 does screen brightness. Works on macOS and Windows.

Install

One double-click per computer

No operating system runs software just because a USB device was plugged in, so the MacroPad carries its own installer on its CIRCUITPY drive. After that, everything is automatic.

Open the drive

Plug in the MacroPad and open CIRCUITPY. It holds the installers, a copy of the background service and a short how-to.

Double-click the installer

Install MacroPad Mixer (Mac).command or (Windows).cmd. It sets up a private Python and the service, installs FineTune on Mac and turns on autostart.

Done for good

The service starts at every login and finds the MacroPad within 2 s of plugging it in. On Mac it also starts FineTune. Mac asks once to allow system audio.

Architecture

Two programs and a USB cable

The MacroPad handles keys, lights and the screen. A small Python service on the computer does the audio and display work, with one backend per operating system. They talk over a second USB serial port that CircuitPython enables in boot.py, so the normal console stays free for debugging.

Protocol v1

One JSON object per line

The knob sends raw clicks; the computer turns them into volume or brightness and answers with the real value, so the computer is always the single source of truth.

DirectionMessageMeaning
Computer → pad{"t":"apps","apps":[…]}One entry per key slot: id, name, vol, mute, plus pin / run:false; null = empty key
Computer → pad{"t":"icon","id":…,"b":…,"c":…}32×32 1-bit logo (base64) and brand colour for the key LED
Computer → pad{"t":"vol","id":…,"vol":55,"mute":false}Current state of one app
Computer → pad{"t":"bright","displays":[…]}Displays with their brightness, for key 12
Computer → pad{"t":"note","text":"Pinned to key 3"}Short message on the status line for 2 s
Computer → pad{"t":"ping"}Heartbeat every 2 s; 6 s of silence means the computer is gone

Platforms

How each OS does it

the hard part

macOS

  • No public per-app volume API. FineTune (free, open source, macOS 15+) does it with Core Audio process taps; we drive it through its finetune:// URL scheme.
  • Playing apps are listed through Core Audio directly.
  • Logos come from AppKit; brand colours from the app's own icon file, since your icon style may tint the rendered icon grey.
  • Brightness: built-in panel via DisplayServices, external monitors via DDC/CI on Apple Silicon.
straightforward

Windows

  • pycaw wraps the same audio-session API the Volume Mixer uses; sessions are grouped per program across every output device.
  • Logos and colours come from each program's own icon.
  • Brightness: laptop panel via WMI, external monitors via the Windows DDC/CI API.
bonus

Linux

  • pulsectl sets per-stream volume on PulseAudio and PipeWire.
  • Paused apps keep their keys even though many drop their stream.
  • No logos or brightness yet. Untested.

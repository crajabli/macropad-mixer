MacroPad Mixer - per-app volume control
=======================================

Install once on each computer you use the MacroPad with:

  Mac:      double-click "Install MacroPad Mixer (Mac).command"
            (if macOS says it can't verify the file: right-click it > Open > Open)
  Windows:  double-click "Install MacroPad Mixer (Windows).cmd"
            (if Windows SmartScreen appears: More info > Run anyway)

The installer downloads what it needs (Python, and FineTune on Mac), so the computer
must be online. Afterwards the mixer starts by itself at every login, and the MacroPad
works as soon as it is plugged in. Nothing else to run.

Using it:
  - Keys light up in the colour of an app that is playing sound.
  - Press a key: the OLED shows that app; turn the knob to change its volume only.
  - Press the knob: mute / unmute that app.
  - Key 12 (bottom right) is screen brightness: press it and turn the knob. Press it
    again to switch between all displays and each display.
  - Hold a key 1.5 s: pin the app to that key. Hold a pinned key, then press another
    key to move it there (same key = unpin, knob = cancel).

Source and help: https://github.com/crajabli/macropad-mixer
